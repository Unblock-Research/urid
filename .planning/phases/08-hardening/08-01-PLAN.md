<task type="auto" tdd="true">
  <name>Task 1: Create the ZodValidationPipe</name>
  <files>packages/api/src/common/zod-validation.pipe.ts</files>
  <read_first>
    - packages/api/src/modules/zk-proofs/zk-proofs.controller.ts (how @Body() params are declared today — the pipe wraps these)
    - packages/api/src/modules/identity/identity.controller.ts (mix of @Body and @Param usage — pipe must handle both)
  </read_first>
  <behavior>
    - Given a schema `z.object({ a: z.string() })` and value `{ a: "x" }`: transform returns `{ a: "x" }` (the parsed data).
    - Given the same schema and value `{}` (missing required field): transform throws BadRequestException (maps to HTTP 400).
    - Given the same schema and value `{ a: 123 }` (wrong type): transform throws BadRequestException.
    - Given a scalar schema `z.string().min(1)` and value `""`: transform throws BadRequestException (supports @Param scalar validation, used by the impact controller).
    - The thrown BadRequestException carries a structured payload of field errors (from Zod's flattened error), never a raw stack trace.
  </behavior>
  <action>
    Create `ZodValidationPipe` implementing NestJS `PipeTransform` from `@nestjs/common`. Constructor takes a single `ZodSchema` (import `ZodSchema` / `z` from `zod`) and stores it on a `private readonly schema`. The pipe is NOT `@Injectable()`-registered globally — it is instantiated per-route as `new ZodValidationPipe(schema)`, honoring the locked per-route decision (HRD-01).

    Implement `transform(value, _metadata)`: call `this.schema.safeParse(value)`. On `result.success === false`, throw `new BadRequestException({ message: "Validation failed", errors: result.error.flatten() })` — the flattened form exposes only field/formErrors, never internals or a stack (mitigates T-08-02). On success, return `result.data` so downstream handlers receive the parsed/typed value.

    Do NOT register a global validation pipe in main.ts and do NOT add Nest's built-in ValidationPipe — Zod is the chosen validator (Claude's Discretion in CONTEXT). Keep the file dependency-free beyond `@nestjs/common` and `zod`.
  </action>
  <verify>
    <automated>cd packages/api && npx tsc --noEmit</automated>
  </verify>
  <done>ZodValidationPipe compiles, implements PipeTransform, constructs with a Zod schema, returns parsed data on success and throws BadRequestException on failure.</done>
</task>
