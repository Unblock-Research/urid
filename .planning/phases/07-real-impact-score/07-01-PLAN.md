<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ORCID/Crossref API → OrcidClient/CrossrefClient | Untrusted external JSON crosses into our process; shape and types are not guaranteed |
| Stored orcidId / work DOI → outbound URL | Values become URL path segments in outbound requests |
| Env config (ORCID_API_BASE/CROSSREF_API_BASE) → axios base URL | Operator-controlled destination for outbound HTTP |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-01 | Tampering/Info-disclosure | ORCID/Crossref JSON parsing | medium | mitigate | Optional-chain every field access; parse only declared fields into typed shapes; never trust presence/type of external keys |
| T-07-02 | Injection | orcidId/DOI → outbound URL path | high | mitigate | `encodeURIComponent` every id/DOI before path interpolation; no string concatenation of raw ids |
| T-07-03 | Denial of Service | Crossref batch fan-out over many DOIs | medium | mitigate | Bounded concurrency cap on `getCitationCounts`; polite-pool mailto; per-request timeout via axios config |
| T-07-04 | Denial of Service | Unbounded/slow upstream response | low | mitigate | axios request timeout so a hung upstream cannot stall the request indefinitely |
| T-07-SC | Tampering | npm installs | low | accept | No new packages — `axios` already present and vetted in package.json; no install step this plan |
</threat_model>
