## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Stored researcher.orcidId + work DOIs → outbound HTTP (via clients) | Persisted values become external requests |
| External ORCID/Crossref data → scoring + persisted ImpactScore | Untrusted data shapes drive computed, stored reputation |
| HTTP client (:did route) → calculate()/getScore() | Public API surface; malformed did/errors must not 500-crash silently |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-07-07 | Spoofing/Info-integrity | ImpactScore persistence | high | mitigate | Only 'scored' pillars (backed by real fetched metrics) contribute to totalScore; data-less pillars are insufficient_data, never fabricated — the stored score cannot claim data it does not have |
| T-07-08 | Denial of Service | calculate() fan-out over a researcher's DOIs | medium | mitigate | Citation fetch delegated to CrossrefClient bounded concurrency (07-01, T-07-03); calculate does not fan out unboundedly |
| T-07-09 | Denial of Service / availability | Upstream API failure during calculate() | medium | mitigate | Client failures degrade the affected pillar to insufficient_data (or surface a typed error) — calculate() never hangs or crashes the request on a single upstream fault |
| T-07-10 | Injection | did/orcidId/DOI reaching outbound URLs | high | mitigate | Encoding enforced in the clients (07-01, T-07-02); service passes ids through the typed client API, never builds URLs itself |
| T-07-SC | Tampering | npm installs | low | accept | No new packages — `axios` already present; no install step this plan |
</threat_model>
