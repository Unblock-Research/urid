  <action>
    Per the locked decision (did:ub method; identifier is the multibase-encoded Ed25519 public key using multiformats base58btc), create packages/api/src/crypto/did.ts exporting async encodeDid(publicKey) and decodeDid(did).

    encodeDid: prepend the ed25519-pub multicodec header bytes (0xed then 0x01) to the 32-byte public key, base58btc-multibase-encode the 34-byte buffer (the encoder emits a leading z multibase prefix), and return the did method prefix for ub concatenated with that string. The 0xed01 header over a 32-byte key yields the standard z6Mk... form.

    decodeDid: strip the did:ub: method prefix, base58btc-multibase-decode the remainder, assert the first two bytes are the ed25519-pub header, and return the remaining 32 bytes. Reject inputs whose method prefix or multicodec header is wrong.

    multiformats v13 is pure ESM and this package builds as CommonJS, so import base58btc via a dynamic import (await import of the multiformats base58 subpath) and cache it at module scope; do not use a top-level static ESM import.

    Write did.spec.ts FIRST: encode a real key from ed25519.generateKeypair, assert the did:ub:z6Mk prefix, assert decode round-trips to the exact input bytes, and assert a malformed string is rejected. Run red, then implement to green.
